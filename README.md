# Iman Hospital Website

A smart hospital website for Iman Hospital, Hassan, Karnataka.

Built with Python, HTML, CSS and JavaScript. Features include:
- Hospital information and services
- Doctor profiles
- Online appointment booking form
- Built-in smart chatbot
